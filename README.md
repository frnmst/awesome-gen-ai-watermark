# Awesome Gen AI Watermark

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)
<a href="https://www.buymeacoffee.com/frnmst" target="_blank"><img src="https://img.shields.io/badge/-buy_me_a%C2%A0coffee-gray?logo=buy-me-a-coffee" alt="Buy Me A Coffee"></a>

Watermarking in generative AI is the practice of inserting, by the gen AI
itself, a watermark by which a third party can detect with some degree of
approximation if some content was possibly generated by an AI system or not.

## General

- [How Claude marks AI-generated content | Claude Help Center](https://support.claude.com/en/articles/16266773-how-claude-marks-ai-generated-content) - Shows which of their models do watermarking, and how detection works and current limitations.

## Text

Gen AI text uses the most fascinating watermark system. These watermarks are
not usually detectable just by analyzing the text.

- [SynthID Text official repo](https://github.com/google-deepmind/synthid-text) - Reference implementation by Google of a tournament-based system.
- [Introducing SynthID Text](https://huggingface.co/blog/synthid-text) - Explains how to implement a SynthID watermark using the official library and a secret key.
- [SynthID Explained: A Technical Deep Dive into DeepMind’s Invisible Watermarking System - DEV Community](https://dev.to/grenishrai/synthid-explained-a-technical-deep-dive-into-deepminds-invisible-watermarking-system-38n7) - Basic overview of SynthID.
- [How Claude’s text watermark works \ Anthropic](https://www.anthropic.com/news/claude-text-watermark) - Basic non technical overview of how text watermarking works.
- [Our approach to EU text provenance rules | OpenAI](https://openai.com/index/eu-text-provenance/) - Semi-technical overview of how OpenAI's system works, its flaws and upcoming plans.

## Research

- [Scalable watermarking for identifying large language model outputs | Nature](https://www.nature.com/articles/s41586-024-08025-4) - The paper that introduced SynthID-
- [Linguistics-Aware Non-Distortionary LLM Watermarking](https://arxiv.org/html/2606.00613v1) - LUNA is an alternative system to SynthID.
- [Official repository of the paper: A Linguistics-Aware LLM Watermarking via Syntactic Predictability (ACL 2026 Main Conference)](https://github.com/Shinwoo-Park/stela_watermark) - Another text watermarking system.
- [textGrain: Entropy-Calibrated Watermarking for Language Model Text](https://cdn.openai.com/pdf/e9508624-d767-41b6-a26d-e34ca798ada6/textgrain-entropy-calibrated-watermarking-for-language-model-text.pdf) - A system used by OpenAI for text watermarking.
